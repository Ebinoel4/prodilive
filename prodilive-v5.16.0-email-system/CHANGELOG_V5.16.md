# PRODILIVE v5.16 — Transactional Email & Admin Alerts

- Added centralized transactional email service using the existing Nodemailer dependency.
- Supports Resend SMTP and any compatible SMTP provider.
- Added branded HTML email templates.
- Welcome email on signup.
- Email verification and resend verification.
- Forgot-password/reset email.
- Admin email on every new user registration.
- Admin email when a provider submits ID verification documents/selfie.
- Admin email when a reviewer application is submitted.
- Admin email when a new support conversation is opened.
- User emails for in-app notifications, including assignment, proposals, delivery, QA, revisions, approval, verification decisions, reviewer decisions, payouts, disputes, refunds and payment confirmation.
- Payment confirmation emails are tied to Paystack verification/webhook processing rather than the browser redirect alone.
