# PRODILIVE v5.60

- Added Back to Home controls to How It Works and Payment Protection visitor pages.
- Wallet now displays the user's saved withdrawal account and its verified/unverified status.
- Added readable bank-name persistence for payout profiles (migration 026).
- Transaction history now starts compact, supports View all / Show less, search, transaction-type filtering, and name/date sorting.
- Withdrawal requests also start compact with View all / Show less.
- Signed-in users no longer see Sign in / Join PRODILIVE links in the footer; they see Profile/Dashboard links instead.
- Admin users no longer see the public Find Talent / Find Jobs / Marketplace platform footer section.
- Added optional tawk.to live chat integration. When TAWK_PROPERTY_ID and TAWK_WIDGET_ID are configured, the tawk.to widget loads and replaces the built-in support bubble. If not configured, the existing built-in support chat remains available.
