# PRODILIVE v5.41 — User-Funded SMS

- Opted-in SMS alerts are paid from the receiving member's PRODILIVE wallet.
- Default SMS alert price is ₦10 and is configurable by Admin.
- Email and in-app notifications remain free.
- SMS wallet charge is reserved before provider submission to prevent overspending.
- Successful provider acceptance completes the SMS charge and records platform SMS revenue.
- Failed provider sends mark the SMS charge FAILED, so the user's wallet is not charged.
- Matching-job SMS now uses the same user-funded path.
- Phone verification SMS remains platform-funded so members can verify before opting into paid alerts.
- Wallet API now reports total SMS charges and the current SMS alert price.
