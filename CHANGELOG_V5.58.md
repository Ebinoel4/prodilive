# PRODILIVE v5.58 — Reviewer invitation onboarding

- Public Reviewer Application remains open but creates no account and asks for no ID.
- Applicant receives an application-received message/email.
- Admin conducts the qualification/test outside the signup flow, then sends a private 7-day single-use invitation.
- Reviewer account can only be created from that invitation.
- Reviewer must submit government ID + selfie after account creation.
- Reviewer tools remain locked until Admin approves identity and Reviewer Terms are accepted.
- Generic Admin role controls can no longer turn an ordinary account into a Reviewer.
- Deposits and withdrawals now require approved identity verification; ordinary marketplace use remains available without ID approval.
- Fixed verification UI bug that incorrectly marked a freshly submitted ID as APPROVED on the client.
