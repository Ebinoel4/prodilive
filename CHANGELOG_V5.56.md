# PRODILIVE v5.56 — Project Protection & Reviewer Controls

- Added structured cancellation/dispute reasons with default work-compensation recommendations.
- Added optional client voluntary compensation/tip percentage during dissatisfaction/cancellation disputes.
- Reviewer decisions now require written reasons and support partial settlements.
- Added Reviewer “Report / Escalate to Admin” action; escalated funds remain frozen pending Admin review.
- Added mandatory Reviewer Terms & Code of Conduct acceptance and stored terms version/timestamp.
- Added automatic chat risk flags for likely off-platform contact/payment attempts with Admin notification and audit logging.
- Extended protected delivery previews to images and video, with project/client watermarks; originals remain private.
- Original masters remain downloadable only after project completion/payment release; cancelled/refunded work stays locked.
- Updated platform Terms for cancellation compensation, file rights, protected previews and reviewer duties.
- Added migration 023_project_protection_reviewer_terms.sql.

Note: browser-level screenshot/screen-recording prevention cannot be guaranteed; visual watermarks and private originals are used as deterrence/protection.
